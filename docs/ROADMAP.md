# Roadmap

| Release | Scope | Target |
|---|---|---|
| 0.1 | Claude Code + Codex ingest, extract, store, CLI review, MCP server, local stats | day 10 |
| 0.2 | Merge same-session duplicates (reversible), weekly digest, decay to archive | day 14 |
| 0.3 | Import from ChatGPT / claude.ai / Gemini exports | after launch |
| 0.4 | Third-party name guard | after launch |

Dates are estimates. Each release ships only after the contributing code has been reviewed
for personal data and for duplicate logic.

Beyond 0.4 the open-source core stays small and local-first. Ideas and contributions that fit
that scope are welcome through issues. Hosted and team offerings, if any, are separate from
this repository and are not part of this roadmap.
